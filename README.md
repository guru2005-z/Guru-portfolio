# Guru-portfolio

> Full-Stack & AI Software Engineer Portfolio - **Guravaiah Katta**

## Overview
A high-performance portfolio featuring an interactive background arcade game engine, real-time Gemini AI agent, interactive engineering architecture demos, and full-stack project showcases.

## Tech Stack
- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS, Framer Motion, Lucide Icons, Canvas Confetti
- **Backend:** Node.js, Express, tsx
- **AI / LLMs:** Google GenAI SDK (`@google/genai`)
- **Contact Service:** FormSubmit integration with direct Gmail dispatch

## Getting Started

### 1. Install Dependencies
```bash
npm install --legacy-peer-deps
```

### 2. Environment Variables
Copy `.env.example` to `.env` (optional):
```bash
PORT=3000
GEMINI_API_KEY="your_gemini_api_key"
```
*(Note: The portfolio includes intelligent built-in responses if no API key is configured)*

### 3. Run Locally
```bash
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.
